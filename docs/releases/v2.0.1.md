# Release Notes: v2.0.1

## Highlights

- Standardized Go module path to `github.com/DongDuong2001/graft` and updated internal imports.
- Set Go toolchain target to Go 1.25 and updated Docker build image accordingly.
- Improved fan-out delivery correctness and concurrency; added `partial_failed` aggregation for multi-destination delivery status.
- Improved worker pool shutdown to be more graceful; added coverage for fan-out and shutdown behavior.
- Hardened Docker Compose service configuration (read-only root filesystem, dropped capabilities, no-new-privileges, tmpfs).
- Refreshed `README.md` and `README-vi.md` for a cleaner, more professional Quick Start.

## Upgrade Notes

- If you import this module in other Go projects, update imports from `Graft/...` to `github.com/DongDuong2001/graft/...`.
- If you run builds/tests that depend on SQLite, ensure you have a working C toolchain and `CGO_ENABLED=1`.
